# 系统部队逐拍复述样本

当前运行时只加载`echo_pata.wav`、`echo_pon.wav`、`echo_don.wav`、`echo_chaka.wav`四个独立样本。它们来自社区档案中真实部队命令复述的首个完整词，与玩家输入鼓点是不同来源文件；不是输入四音的同文件别名，也没有新增AI/TTS生成或音乐层。

每个文件为PCM16、44.1kHz、双声道、20948帧，时长475.011ms，峰值约-2.30dBFS。保留Pata和Chaka的完整双音节，再用CPU ffmpeg atempo保音高压缩；140Hz高通、8/13ms左右轻展开、3ms起音与末8ms尾淡出。精确切片、参数、源URL/SHA及输出SHA见[echo_manifest.json](echo_manifest.json)，以该清单为制作依据。

四字指令在tick C完成后，模拟分别在C+30/60/90/120发送同句四次实际复述事件，AudioRouter逐次选择对应echo；120BPM的每拍间隔为500ms，文件保留自然尾。C+150结束真实复述并允许新首拍。声音只跟随已执行事件，不调度伤害或生成额外指令；暂停、静音和音量作用于实际播放。

原始整句保留在外层`../../../参考音频/Patapon扩展/Patapon3/命令复述-通用/`，复建脚本位于该素材库的`build_echo_v12.py`。来源属于TheSandKid社区游戏音频提取档案，未确立官方或商用授权。代理的波形/哈希检查不等于词义和合唱主观听感已获用户验收。
