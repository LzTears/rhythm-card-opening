# 圆卡旋风音频

当前战斗采用四个原版鼓点输入和四个独立部队合唱复述样本。节拍由60Hz模拟控制，120BPM；声音消费真实输入/复述事件，不承担判定、伤害或奖励时钟。

## 运行时文件

| 路径 | 用途 |
| --- | --- |
| `patapon_build_v8/pata.wav`、`pon.wav`、`don.wav`、`chaka.wav` | 玩家逐键输入原音 |
| `patapon_cadence_v12/echo_pata.wav`、`echo_pon.wav`、`echo_don.wav`、`echo_chaka.wav` | 系统按本次成功指令逐拍复述 |
| `music/menu.ogg` | 菜单、卡组、天赋等局外音乐 |
| `sfx/ui_click.wav` | 界面点击，战斗中操作GUI仍可播放 |
| `sfx/`其余当前资源 | 保留通用路由用于局外结算/升级等既有调用；按真实调用触发 |

战斗进入后停止音乐播放器，不加载战斗BGM；通用命中、裂包和奖励叠层在战斗中被路由抑制。完整句试听文件不参与运行时播放。目录名称只用于稳定资源路径，不表示启动旧玩法。

输入样本与echo各自独立加载，缺失时不能自动回退成另一声族。音乐/音效设置、静音、暂停和恢复须覆盖实际播放器，避免恢复后补发已错过的声音。声音变化须与真实模拟事件核对，不能听到回应就推定伤害已经执行。

## 原音来源与制作记录

四输入WAV是社区提取原样本的字节副本，对应外层`../../../参考音频/Patapon原版/`的Pata-3、Pon-3、Don-3、Chaka-3。选用文件、URL、SHA及权利边界见[`patapon_build_v8/manifest.json`](patapon_build_v8/manifest.json)。

四echo由外层`../../../参考音频/Patapon扩展/Patapon3/命令复述-通用/`的真实部队命令复述源切片、保音高压缩并轻微立体声展开；没有新增AI/TTS生成或音乐层，也不是输入单音的同文件别名。精确源文件、切片、滤波/层叠参数及输出SHA见[`patapon_cadence_v12/echo_manifest.json`](patapon_cadence_v12/echo_manifest.json)。复建脚本位于外层`参考音频/Patapon扩展/build_echo_v12.py`。

外层原版12WAV和扩展45WAV及下载清单是当前素材源库，保留原字节与来源记录。`source/`中的当前制作输入、生成记录和处理脚本用于追溯现有通用资源；文件名中的制作批次不代表当前战斗会调用该声音。不要无意重跑生成或母带脚本覆盖现有成品。

社区音源来自TheSandKid公开提取档案，并非项目原创录制；未独立与官方游戏资源逐字节比对，未确立商用复用授权。模型制作的通用资源沿用各自manifest中的生成记录；本机安装记录显示曾接受模型条款，但未独立核验当前商用许可及训练来源，不声称商用授权。发行前需完成相应许可确认及主观听音。

## 验证

当前音频验证入口为`../../verification/current/target_audio.gd`，QA结果统一输出`user://qa-current/`。验证八个实际文件、来源/输出SHA、真实输入与逐拍回应顺序、暂停/恢复/音量/静音，以及战斗无持续BGM和多余叠层。客观格式、波形或哈希检查不等于音色、词义及合唱听感已获用户验收。
