- 最终完整提示词：`prompt.txt`。
- 原始生成文件：`source-atlas.png`，1448×1086，RGBA；顺序为第一行 ×、0、1、2，第二行3、4、5、6，第三行7、8、9。
- 原输出：`C:/Users/Administrator/.codex/generated_images/01a1cfd2-cec2-7f61-90b6-0a07d7f895cd/exec-18b940d6-2805-4f50-a4e6-0c988e72cfa1.png`；项目内已保留完整副本，无外部运行依赖。

- `manifest.json` 保存原图、提示词及逐字文件SHA-256、源图裁切矩形。

## 交付文件与推荐拼法

`x.png` 是乘号 ×；数字为 `0.png` 至 `9.png`，各自透明RGBA。均保留完整原始字形与原alpha，在紧裁矩形外另加2像素完全透明边距。裁切定位忽略alpha小于16的近透明生成毛边，但矩形内部alpha不修改。没有缩放、重绘、改色或字形替换。

按字符选图并保持每图宽高比，数字统一显示高度，乘号推荐为数字高度的0.78倍、垂直居中。相邻字间距推荐数字高度的0.035倍（64设计像素高时约2px）。用于左上Combo区时建议数字高64设计像素，整体外框可统一缩放；×99宽约162px。每次从真实Combo格式化字符，不预生成99张全图。

`preview.png` 为实际交付PNG在紫色底上的检查图，包含完整字形与×1、×10、×99三个组合；是检查用，不作为游戏纹理。

## 核查范围
