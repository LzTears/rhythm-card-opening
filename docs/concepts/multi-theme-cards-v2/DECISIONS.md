# 多主题收藏卡方案确认

2026-11-12，用户确认：采用共用模板，主题保留各自画风。

- 共用：卡片尺寸、五阶品质边框、名称和描述区布局。
- 主题独立：插画画风、主题徽记、少量装饰与卡册封面。
- 星系首批计划49张；其他主题独立扩展，不强制相同卡数。
- 当前两张五阶效果板为方向参考，卡片比例和框角细节需统一后再制作正式资源。
- 样卡品阶分配仅作视觉示范，不是正式卡表或掉落配置。
- 收藏、产卡及HUD尚未开始实现；隐藏款关系、掉落规则、49张正式卡表及其余体验继续逐项确认。

## 红色与隐藏款（已确认）

仍为五阶白普通／绿稀有／紫史诗／金传说／红绝版；少量指定红卡显示特殊品阶名隐藏款，配专属徽记与闪光。隐藏款为卡片固定身份，不是随机附加版本；战斗红色计数包含绝版与隐藏款，不增第六计数。

## 卡包产卡方式（已确认）

每个真实击破的卡包必得1张卡；卡包品阶影响五阶卡片的随机概率，不直接锁定卡片品阶。未击破不产卡，圈内金币×2不额外增加卡片数量。具体概率待下一项确认。

## 隐藏款权重（已确认）

按五阶概率表抽到红阶后，以95%进入普通绝版卡池、5%进入隐藏款卡池，各池内部等概率抽指定卡。隐藏款仍为固定卡片身份；与普通绝版共用红色战斗计数。暂不设保底，平均20张红卡约1张隐藏款不等于保证每20张必出。

大量同卡合并成一张＋数量，新卡首张入册、其余兑换；支持加速／跳过。结算先统一保存奖励，动画只展示结果，不影响到账、不重复领取。以卡图／图标／数字为主，不铺说明文字。先出四阶段静态流程参考图，尚非已实现演出。
