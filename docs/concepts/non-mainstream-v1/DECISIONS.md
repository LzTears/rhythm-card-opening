# 非主流收藏主题：首轮样卡

用户2026-11-13要求新增49张，以中国大陆当前流行的抽象表情包为主题，先做3张效果图确认。此目录仅概念样张，不增加正式卡池、概率或收藏总数，49张卡表与分阶在外观确认后再收敛。

首轮选择圆头耄耋（白普通）、奶蛙（紫史诗）、高雅人士（红绝版）展示共用3:4模板和品质递进。三种画面分别保留猫梗照片、怪诞3D奶蛙、3D企鹅的来源气质；共用正式框、运行时排字与红卡Holo。品阶在此只是配色示例，不代表49张正式配置。
