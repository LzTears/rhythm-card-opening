# 节拍开卡1.0 · Windows x64

四拍发令，连击爆发，把一桌卡包变成你的收藏。

**[下载节拍开卡1.0](https://github.com/LzTears/rhythm-card-opening/releases/download/v1.0/1.0.zip)** · [游戏介绍、截图与操作](https://github.com/LzTears/rhythm-card-opening#readme)

## 版本内容

- 90秒单局、120 BPM、四鼓四指令；聚拢、扩圈、自动合成与开卡。
- Fever基础5连击就绪，天赋可降至4／3／2；能量充满时爆发可全屏开包。
- 三主题147张收藏卡、20类天赋、5条成长路线，以及三类可混搭外观。
- 支持键鼠与Xbox布局手柄，局末自动保存，局外可手动保存。

## 下载与启动

下载游戏附件，完整解压 `节拍开卡1.0` 文件夹，运行 `节拍开卡.exe`。保持PCK及三个DLL同目录，无需安装Godot或Python。适用于64位Windows，需要支持OpenGL 3.3的显卡。

GitHub将中文附件文件名规整为 `1.0.zip`，显示名称为“节拍开卡1.0.zip”，大小163,019,999字节（约155.47 MiB）。下载后可重命名。自动附带的Source code为开发源码。

普通入口沿用本机已有进度；包内 `独立新档启动.cmd` 使用单独目录，从空档开始并持续保存，不清除原有进度。
